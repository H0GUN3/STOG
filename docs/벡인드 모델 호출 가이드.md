\## \*\*3. 💻 Spring Boot Service 구현 코드 예시\*\*



최신 Spring Boot에서 권장하는 \*\*`RestClient`\*\* (또는 기존 \*\*`RestTemplate`\*\*) 이용 구현 예시입니다.



```

java



importorg.springframework.stereotype.Service;

importorg.springframework.web.client.RestClient;

importlombok.RequiredArgsConstructor;

@Service

@RequiredArgsConstructor

publicclassStogRecommendService{

privatestaticfinalStringAI\_API\_URL="https://stog-recommend-api-824014926086.asia-northeast3.run.app/api/recommend";

privatefinalRestClient restClient=RestClient.create();

/\*\*

&#x20;    \* 유저 성향 및 조건을 받아 AI 추천 API 호출

&#x20;    \*/

publicStogRecommendResponsegetRecommendations(UserPreference userPref,String gunguFilter,int topN){



// 1. AI 서버용 요청 DTO 빌드

StogRecommendRequest requestDto=StogRecommendRequest.builder()

.user\_nature(userPref.getNature())

.user\_culture(userPref.getCulture())

.user\_food(userPref.getFood())

.user\_shopping(userPref.getShopping())

.user\_experience(userPref.getExperience())

.user\_relaxation(userPref.getRelaxation())

.gungu\_filter(gunguFilter)// 예: "전주시" 또는 null

.top\_n(topN)// 예: 5

.build();

// 2. GCP Cloud Run AI 서버에 HTTP POST 요청전송 및 응답수신

return restClient.post()

.uri(AI\_API\_URL)

.header("Content-Type","application/json")

.body(requestDto)

.retrieve()

.body(StogRecommendResponse.class);

}

}

```

\## \*\*4. 🔄 백엔드 전체 처리 워크플로우\*\*



1\. \*\*\[요청 대기]\*\* 프론트엔드에서 `GET /api/v1/travel/recommend?gungu=전주시` 요청 수신.

2\. \*\*\[DB 조회]\*\* 현재 로그인한 유저 ID로 데이터베이스(`user` 테이블)에서 유저 6축 성향값 조회.

3\. \*\*\[AI 통신]\*\* 위 `StogRecommendService`를 호출하여 GCP Cloud Run AI 서버로 \*\*HTTP POST\*\* 통신 ➔ \*\*Top-5 장소 리스트 수신\*\*.

4\. \*\*\[DB 조인]\*\* 반환된 장소명(`place\_name`)으로 데이터베이스(`place` 테이블)를 조회하여 \*\*장소 이미지 URL, 주소, 지도 링크\*\* 추가 결합.

5\. \*\*\[최종 반환]\*\* 프론트엔드로 조인된 데이터 전송 ➔ 프론트엔드 화면에 \*\*추천 카드 및 6축 레이더 차트\*\* 렌더링.
