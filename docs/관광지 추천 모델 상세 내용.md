\## 2. 👤 사용자 6축 성향 전처리 알고리즘 (User Profile Preprocessing)



사용자 성향 벡터 $\\vec{U} \\in \\mathbb{R}^6$는 유저의 설문 항목(`TRAVEL\_STYL\_1\~8`)과 심리적 여행 동기(`TRAVEL\_MOTIVE\_1`)를 결합하여 \*\*$0.0 \\sim 1.0$ 실수 연속형 분포\*\*로 산출됩니다.



\### 📐 6대 성향 정규화 산출 수식



| 성향축 | 연동 설문 변수 (`TRAVEL\_STYL`) | 보조 여행 동기 (`TRAVEL\_MOTIVE\_1`) | 정규화 파이썬 수식 ($0.0 \\sim 1.0$) |

| :---: | :--- | :--- | :--- |

| \*\*`nature`\*\* (자연) | `STYL\_1` \*(자연 1점 \~ 도시 7점)\* | `MOTIVE == 6` \*(운동/건강)\* | `(7 - STYL\_1) / 6.0 \* 0.8 + (MOTIVE==6)\*0.2` |

| \*\*`culture`\*\* (역사·문화) | `STYL\_4` \*(휴양 1점 \~ 역사문화 7점)\* | `MOTIVE == 8` \*(역사탐방)\* | `(STYL\_4 - 1) / 6.0 \* 0.7 + (MOTIVE==8)\*0.3` |

| \*\*`food`\*\* (미식) | `STYL\_5` \*(식도락 1점 \~ 맛집필수 7점)\* | `MOTIVE == 3` \*(미식탐방)\* | `(STYL\_5 - 1) / 6.0 \* 0.7 + (MOTIVE==3)\*0.3` |

| \*\*`shopping`\*\* (쇼핑) | `STYL\_8` \*(쇼핑 1점 \~ 쇼핑필수 7점)\* | - \*(STYL\_3 로컬 노이즈 제거)\* | `(STYL\_8 - 1) / 6.0` |

| \*\*`experience`\*\* (체험) | `STYL\_6` \*(관람 1점 \~ 체험/축제 7점)\* | `MOTIVE == 7` \*(신규경험)\* | `(STYL\_6 - 1) / 6.0 \* 0.7 + (MOTIVE==7)\*0.3` |

| \*\*`relaxation`\*\* (휴식) | `STYL\_7` \*(휴식)\* + `STYL\_4` \*(휴양)\* | `MOTIVE == 2` \*(피로해결)\* | `(7-STYL\_7)/6.0\*0.4 + (7-STYL\_4)/6.0\*0.4 + (MOTIVE==2)\*0.2` |

\## 3. 📍 장소 6축 임베딩 전처리 알고리즘 (정체성 강화 3중 베이지안 융합)



초기 모델에서 발생했던 \*\*'인구 평균 희석(Dilution)' 현상\*\*(대다수 여행객의 미식 선호도가 높아 역사유적지의 정체성이 미식으로 뭉개지는 현상)을 완벽히 해결하기 위해, 카테고리 사전 기저(Prior)의 가중치를 단단한 닻(Anchor)으로 고정하여 융합합니다. 2022+2023 통합 데이터를 기반으로 \*\*총 3,290개 전북 관광지\*\*의 임베딩이 추출되었습니다.



\### 📐 3중 융합 가중치 공식



$$\\mathbf{\\vec{P}\_j} = \\frac{10.0 \\cdot \\mathbf{\\vec{P}}\_{\\text{prior}} + w\_{\\text{vis}} \\cdot \\mathbf{\\vec{P}}\_{\\text{vis}} + w\_{\\text{act}} \\cdot \\mathbf{\\vec{P}}\_{\\text{act}}}{10.0 + w\_{\\text{vis}} + w\_{\\text{act}}}$$



$$\\mathbf{P}\_{\\text{final}} = \\mathbf{P}\_{\\text{blended}} \\times 0.9 + \\left(\\frac{\\text{place\\\_mean\\\_score}}{5.0}\\right) \\times 0.1$$



| 융합 단계 | 소스 데이터 | 동적 가중치 스케일링 공식 | 핵심 역할 |

| :--- | :--- | :---: | :--- |

| \*\*1단계: 카테고리 사전 기저\*\* ($\\vec{P}\_{\\text{prior}}$) | `VISIT\_AREA\_TYPE\_CD` (1\~24) | \*\*$w\_{\\text{prior}} = 10.0$ (고정 닻)\*\* | \*\*장소 고유 정체성 보존\*\*: 일반인 평균 성향에 의해 장소 본연의 색깔이 훼손되는 것을 방어 (콜드 스타트 100% 방지) |

| \*\*2단계: 만족 방문자 성향\*\* ($\\vec{P}\_{\\text{vis}}$) | 평점 3.5점 이상 만족 유저 성향 | \*\*$w\_{\\text{vis}} = \\min(N\_{\\text{vis}}, 10) \\times 0.4$\*\* | \*\*유저 취향 적합도\*\*: 만족 방문객의 성향을 장소 정체성을 해치지 않는 범위($\\pm 10 \\sim 20\\%$)에서 미세 보정 |

| \*\*3단계: 방문활동 현장 실측\*\* ($\\vec{P}\_{\\text{act}}$) | `tn\_activity\_his` (ACT 1\~7) + NLP | \*\*$w\_{\\text{act}} = \\min(M\_{\\text{act}}, 10) \\times 0.4$\*\* | \*\*현장 행동 실측\*\*: 취식(1), 쇼핑(2), 관람(3), 산책(4), 휴식(5), 문화 텍스트 파싱 비율 반영 |

\## 4. 🔄 2차 연계 동선 추천 알고리즘 (하이브리드 마르코프 체인)



사용자가 추천된 특정 장소 $A$를 선택하거나 \[다음 경로 추천] 버튼을 누를 때, \*\*$A \\rightarrow B(x\\%) \\rightarrow C(y\\%)$ 연계 코스를 실시간 추천\*\*합니다.



\### 📐 연계 경로 추천 연산 2단계

1\. \*\*\[1단계] 마르코프 전이 확률 ($x\\%$) 추출\*\*:

&#x20;  $$\\text{Trans\\\_Prob}(A \\rightarrow B) = \\frac{\\text{Count}(A \\rightarrow B)}{\\sum\_k \\text{Count}(A \\rightarrow k)} \\times 100\\%$$

2\. \*\*\[2단계] STOG 6축 사용자 성향 맞춤점수 (100점 만점) 결합\*\*:

&#x20;  $$\\text{User\\\_Match\\\_Score}(U, P\_B) = \\text{round}\\left(\\frac{\\vec{U} \\cdot \\vec{P}\_B}{\\|\\vec{U}\\| \\|\\vec{P}\_B\\|} \\times 100\\right)$$



\### 📱 프론트엔드 연동 듀얼 뷰 지원

\- \*\*`\[🎯 나만의 맞춤순]` (기본 뷰)\*\*: \*\*맞춤점수(78점 > 69점 > 61점)\*\* 높은 순 정렬

\- \*\*`\[🔥 인기 동선순]` (선택 뷰)\*\*: \*\*마르코프 통행 확률(45.2% > 38.0% > 20.1%)\*\* 높은 순 정렬

\## 5. ☁️ 통합 머신러닝 파이프라인 구성 (GCP 인프라 적용)



초기 Kaggle 환경에서 벗어나, \*\*Google Cloud Platform (GCE + GCS)\*\* 환경에서 2022년과 2023년 데이터를 모두 통합한 단일 파이프라인(`STOG\_model\_merged.py`)으로 고도화되었습니다.



\### 🗄️ 통합 데이터셋 구성 (2022 + 2023 병합)

\- \*\*원천 데이터 (GCS)\*\*: `gs://travel-ml-data/dataset/2022/` 및 `2023/`의 멀티파트 tar 압축 데이터

\- \*\*학습용 (TL)\*\*: 2022 + 2023 Training 데이터 병합 (총 63,174건 방문 로그 ➔ \*\*전북 정제 8,003행 학습\*\*)

\- \*\*검증용 (VL)\*\*: 2022 + 2023 Validation 데이터 병합 (총 7,834건 방문 로그 ➔ \*\*전북 정제 559행 검증\*\*)



\### ⚙️ 최종 산출물 및 모델 성능

1\. \*\*`jeonbuk\_place\_embeddings\_merged.csv`\*\*:

&#x20;  - \*\*총 3,290개\*\* 전북 관광지의 6축 임베딩 벡터 추출 완료 (2022년 단독 1,580개 대비 2.1배 확장).

&#x20;  - 1회성 방문 장소(롱테일)도 베이지안 기저치(Prior)를 통해 안전하고 직관적인 벡터로 추천 풀에 포함.

2\. \*\*`STOG\_model\_merged.cbm` (CatBoostRegressor 모델)\*\*:

&#x20;  - \*\*검증 오차(Test RMSE)\*\*: \*\*`0.5776`\*\* (1.0\~5.0 평점 예측에서 평균 오차 약 0.5점 내외의 탁월한 실제 일반화 성능 증명).

&#x20;  - \*\*Early Stopping\*\*: 159번째 이터레이션에서 최적 성능을 포착하여 과적합 방지 및 학습 자동 종료.

\## 7. 🛠️ 핵심 데이터 엔지니어링 및 결측치 복원 전처리 명세



원천 데이터셋의 구조적 결함과 결측치를 해결하기 위해 적용된 \*\*2대 핵심 데이터 엔지니어링 전처리 알고리즘 명세\*\*입니다.



\### 🔄 \[전처리 1] 이동내역(`tn\_move\_his`) 출발지 결측 복원 알고리즘 (`VISIT\_ORDER` Shift 연계)

\- \*\*원천 데이터의 구조적 문제\*\*:

&#x20; - `tn\_move\_his` 파일은 모바일 설문 앱의 "도착지 중심 입력 구조"로 인해 도착지(`END\_VISIT\_AREA\_ID`)는 100% 채워져 있으나, \*\*출발지(`START\_VISIT\_AREA\_ID`)는 90.3%(3,926건)가 결측치(`NaN`)\*\*로 유실되어 있었습니다.

\- \*\*복원 알고리즘 원리\*\*:

&#x20; - `tn\_visit\_area\_info`에는 동일 여행(`TRAVEL\_ID`) 내에서 여행객이 방문한 순서가 \*\*`VISIT\_ORDER` (1번째 ➔ 2번째 ➔ 3번째...)\*\*로 완벽하게 보존되어 있습니다.

&#x20; - 판다스 `groupby('TRAVEL\_ID')\['VISIT\_AREA\_NM'].shift(-1)` 연산을 적용하여, \*\*이전 방문지($A$)와 다음 방문지($B$)를 1:1로 정확하게 연결하는 1,726개의 전이 경로를 100% 온전하게 복원\*\*했습니다.

```python

\# 이동내역 출발지 결측 복원 파이썬 코드

v\_df = visit\_area\_info.sort\_values(by=\['TRAVEL\_ID', 'VISIT\_ORDER']).copy()

v\_df\['next\_place\_nm'] = v\_df.groupby('TRAVEL\_ID')\['VISIT\_AREA\_NM'].shift(-1)

valid\_moves = v\_df.dropna(subset=\['VISIT\_AREA\_NM', 'next\_place\_nm'])

valid\_moves = valid\_moves\[valid\_moves\['VISIT\_AREA\_NM'] != valid\_moves\['next\_place\_nm']]

trans\_matrix = valid\_moves.groupby(\['VISIT\_AREA\_NM', 'next\_place\_nm']).size().reset\_index(name='count')

```



\### 🔍 \[전처리 2] 방문활동(`ACT`) 비정형 텍스트의 문화 키워드 NLP 정밀 파싱 알고리즘

\- \*\*원천 데이터의 구조적 문제\*\*:

&#x20; - `tn\_activity\_his`의 활동 코드(`ACTIVITY\_TYPE\_CD`)에는 식사(1), 쇼핑(2), 관람(3), 산책(4), 휴식(5)만 존재하고, \*\*'역사/문화 탐방' 전용 독립 코드가 부재하여 대부분 '6.기타' 또는 '3.입장/관람'으로 분류되어 유실\*\*되고 있었습니다.

\- \*\*NLP 정밀 파싱 알고리즘 원리\*\*:

&#x20; - 방문자가 자유롭게 작성한 상세 활동 텍스트(`ACTIVITY\_DTL`)를 자연어 정규식 파서로 스캔하여, \*\*16대 문화·역사 핵심 키워드\*\*가 포함된 경우 이를 \*\*독립적인 `culture` 성향 활동으로 재배치\*\*했습니다.

&#x20; - 키워드 풀 (16종): `'문화'`, `'역사'`, `'전시'`, `'박물관'`, `'미술'`, `'공연'`, `'유적'`, `'사적'`, `'사찰'`, `'향교'`, `'서원'`, `'해설'`, `'한옥'`, `'고궁'`, `'문학관'`, `'경기전'`

culture\_keywords = \['문화', '역사', '전시', '박물관', '미술', '공연', '유적', '사적', '사찰', '향교', '서원', '해설', '한옥', '고궁', '문학관', '경기전']



def classify\_activity(row):

&#x20;   cd = row.get('ACTIVITY\_TYPE\_CD', 0)

&#x20;   dtl = str(row.get('ACTIVITY\_DTL', ''))

&#x20;   

&#x20;   # 6번(기타) 및 3번(입장/관람) 텍스트 중 문화/역사 키워드 감지 시 culture로 정밀 분리

&#x20;   if any(k in dtl for k in culture\_keywords): 

&#x20;       return 'culture'

&#x20;   if cd == 1: return 'food'         # 1. 취식
